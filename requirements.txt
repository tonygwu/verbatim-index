# Picks which of the operator's Claude subscriptions runs each Fable judge call,
# by measured remaining Fable quota. grade.py imports it as a library; with a
# single Claude account it still installs and simply reports one account.
#
# v0.1.1 or newer is required, not just preferred. v0.1.0 derived the
# interactive fleet from a builtin map of four accounts, so a fifth account was
# visible to `quotapick status` and to load_config(), and absent from
# select_account()'s candidate set. The library then reported every account
# exhausted while the new one had a full window. 0a74583 derives the fleet from
# the config instead. v0.1.1 is also the first release whose dist reports its
# own version, so `pip show` can tell the fixed build from the broken one.
