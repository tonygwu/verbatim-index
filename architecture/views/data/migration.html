[owned-output] Owned experiment files

text · existing · verified

Only explicitly named run directories are copied. Source and destination files must have equal SHA-256 hashes.

Where this data travels

  • Shared production checkout -> Agent-owned experiment checkout: Copy explicitly owned outputs with hash checks [preserve]

Fields and constraints

  • path: predictions/_experiments/UNIQUE-RUN/relative-file
  • bytes: regular file content
  • digest: SHA-256 of file content
